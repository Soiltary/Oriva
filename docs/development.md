# Development

Use Node 22.13+ and the pinned pnpm 11.25.0 toolchain. Preserve `pnpm-workspace.yaml` supply-chain rules and the lockfile. Install with `pnpm install --frozen-lockfile --ignore-scripts`. No package lifecycle script is required by the documented pure tests. Keep dependency directories and local data out of Git.

Run `node tests/run.mjs`, `node node_modules/typescript/bin/tsc --noEmit --incremental false`, and `node scripts/run-framework.mjs build`. Actual D1/R2 and paired recovery checks used private disposable local verification tools, excluded from this public export. Public regression tests use in-memory fixtures with per-run generated inputs and no live accounts. For a browser preview, configure only isolated local bindings and apply migrations locally; use `wrangler.local.json` and the commands in development.md. Do not turn local commands into remote commands.

Native source compiles with Zig 0.14.1 and Windows system libraries; commands are in desktop/windows/README.md. Compile into a separate workspace directory. Building production configuration does not authorize executing it against real accounts or running its installer. Native pure console tests exercise parsers/collections/mutations/language/updater without installation.

The public hosting example omits the private Site project_id. Configure your own authorized Site only when publication is intended; local tests do not require a hosted project. The checked-in `wrangler.local.json` uses only a zero-UUID D1 binding and local R2. Build, then apply migrations with `node node_modules/wrangler/bin/wrangler.js d 1 migrations apply DB --local --config wrangler.local.json --persist-to work/local-data`. Start with `node node_modules/wrangler/bin/wrangler.js dev --config wrangler.local.json --local --persist-to work/local-data --ip 127.0.0.1 --port 5190 --inspector-port 0`. Open the local address only with synthetic data. Browser Secure-cookie behavior depends on loopback host/protocol; the disposable API regressions are the authoritative automated auth checks. Do not remove production cookie attributes to work around a local browser setting.

The private provider recovery rehearsal used only disposable local bindings. Its outcome is described in the recovery plan; it does not prove managed provider recovery.

The public export omits optional private connector-preview and local identity emulation. It preserves Oriva’s own authentication and shared API. The public native source is the production view and refuses the private staging compiler flag rather than falling back to a production connection. Private staging guards remain intact in the private development checkout.
