# التثبيت

[English](installation.md) · [القبول الحالي](release-acceptance.ar.md)

الهدف Windows10/11 x64. جرى قبول الواجهة والتثبيت والتحديث وإعادة التشغيل للملف النهائي داخل ضيف Windows11 معزول. لا يلزم محرك متصفح مرفق أو Python أو.NET؛ تحتاج عمليات السحابة الإنترنت. الملف غير موقّع والبصمات تثبت البايتات ولا تثبت هوية ناشر مستقل. لا تتجاوز تحذيرات النظام. لم يكتمل اختبار High-DPI أو كل الأجهزة الفعلية؛ يحتاج تخطيط المكتبة المعتاد850×720 بكسل لمساحة العمل عند مقياس الاختبار.

ثبّت الحزمة الرسمية بعد نشرها في صفحة إصدارات المستودع فقط. تحقق من SHA-256 لملف ZIP، وفك جميع الملفات وتحقق من FILE-SHA256SUMS.txt ثم شغّل Setup.cmd في حساب Windows الخاص بك. يضيف الاختصارات وتكامل Explorer دون صلاحيات المدير. حُفظ تطبيق المالك المثبّت وسجل جهازه؛ اقتصر تغيير التثبيت والتحديث على ضيف مؤقت.

أنشئ حسابًا من الموقع واحفظ رمز الاستعادة لمرة واحدة بسرية ثم سجّل الدخول من أجهزتك. لا توجد خدمة تحقق بريد أو إعادة تعيين بالبريد؛ يتطلب استرداد كلمة المرور رمز الحساب. لا تضع بيانات حقيقية أو رموزًا في التقارير. نُشر API الإنتاج المتوافق.

تعرض قائمة Explorer ‏Save to Oriva شاشة تسمية وتأكيد. قد تظهر تحت «إظهار المزيد من الخيارات» في Windows11، ولا يتغير اسم الملف الأصلي. تدعم أيقونة الشريط الإخفاء وإعادة الفتح والخروج الصريح Exit Oriva. يزيل Remove-context-menu.cmd تكامل Explorer فقط؛ لا يزيل التطبيق كاملًا ولا يحذف بيانات السحابة. المحرر الأصلي نصّي/Markdown والمعاينة المرئية في الموقع دون تحرير دائم للمستندات بلا اتصال.

رقم المنتج1.0.0 وترتيب التحديث2.0.0 لاستمرار ترتيب نسخ التطوير الداخلية. يجب أن تعرّف بيانات التحديث المتوافقة البايتات الموثّقة نفسها. يتطلب المحدّث استجابة HTTPS200 مباشرة من المصدر نفسه مع الحجم وSHA-256؛ لا يتبع تحويلات GitHub. تفعيل بيانات التحديث وتسليم الجمهور ما زالا معلقين؛ راجع [انتقال التحديث](update-transition.md).
