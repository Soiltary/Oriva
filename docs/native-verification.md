Source preparation continues. No Stable release, official Windows download, production migration, deployment or update-feed activation is authorized by these results.

The existing native library now retains all records in its model while exposing at most 200 rows per page. Search covers the complete model. Exact collection grouping, collapse/expand, Unicode, page navigation and source-index selection have regression coverage. The real hidden Win32 control fixture visits every source ID at 100, 1,000, 5,000 and 10,000 items. A single 10,000-item public-source sample measured load 6.836 ms, search 8.311 ms, groups 5.344 ms and refresh 1.650 ms at 18,661,376 bytes working set. These are local control measurements, not production latency or endurance results. The actual isolated 10,000-item GUI accepted global search, favorite, archive/restore, collection collapse, page navigation and Arabic switching after unrestricted accessibility enumeration previously stalled the window.

The updater previously returned success after its launch operation failed. It now checks launch status and restores the verified previous bytes before attempting the previous executable again. The isolated filesystem fixture covers wrong hashes, replacement, previous-copy integrity, immediate launch failure, rollback/relaunch and a preserved settings sentinel. It launches only its own synthetic fixture. Installed upgrades, HTTPS download, signing and recovery from a process that starts then crashes remain unverified.

Owned native editor windows now appear separately for accessibility targeting while retaining their owner and modal behavior. A multiline Windows edit control does not normally send EN_CHANGE for WM_SETTEXT/UI Automation SetValue. This caused a visible edit to retain a false Saved state. The fix relays that notification while suppressing application-driven initialization and revision loads. The real-control fixture checks the original omission, relayed edits, load/restore suppression, ordinary input against its native notification baseline, and 100 repeated edits. Actual staging GUI/API readback proved the formerly lost edit became revision 3 and restoring revision 2 through the GUI created revision 4 with the original Arabic/English text.

The 22-suite synthetic regression runner passes. Legacy 1.5.3 full seven-field writes without a revision return 428 and retain newer note/collection edits; upgraded narrow mutations and concurrent revision checks are tested. This is explicit protection, not transparent legacy write compatibility. Existing update-order tests retain public product 1.0.0 with monotonic compatibility version 2.0.0.
