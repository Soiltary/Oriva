# قبول الإصدار — 29 أكتوبر 2026

[English](release-acceptance.md) · [الملف التعريفي](../README.ar.md)

هذه الحالة الحالية؛ تقارير التدقيق والترحيل المؤرخة الأقدم تصف مراحل تاريخية. أصبح مشروع Sites الحالي على النسخة 18 مع API والمخطط الإضافي المتوافقين. وافق المالك صراحةً على مخاطرة هذه العملية المحددة دون نسخة مزوّد شاملة. لم تُصفّر قاعدة البيانات ولم تُحذف حسابات أو تُنقل ملفات التخزين.

أُعيد إنتاج عيبين إضافيين وأُصلحا: توسيع نافذة الدخول إلى المكتبة قد يضع الأزرار السفلية خارج مساحة الشاشة؛ وفشل قراءة الإصدارات كان يحظر الحفظ التلقائي بينما تظل رسالة الفشل بعد نجاح المحاولة. تختبر حالات الانحدار معالجي التخطيط والاستجابة الأصليين، بالعربية والإنجليزية، بما يشمل الردود التالفة والمسودات وتعارضات الحفظ السابقة.

مرشح Windows بنية x64 وغير موقّع، ورقم المنتج والملف 1.0.0. يبقى ترتيب التحديث 2.0.0 لاستمرار ترتيب النسخ الداخلية. يحتاج تخطيط المكتبة المعتاد مساحة عمل تكفي الحد القائم 850×720 بكسل فعلي عند مقياس الاختبار؛ نجاح احتواء الإطار في مساحة أصغر لا يثبت صلاحية كل الأزرار فيها. لا تُستنتج نتيجة High-DPI من الصور أو تكبيرها.

لا تُفعّل روابط التنزيل الرسمية أو بيانات التحديث قبل نشر الأصل النهائي وتنزيله والتحقق من SHA-256. احفظ تطبيق المالك المثبّت، واختبر التثبيت والتحديث في ضيف مؤقت بحسابات اصطناعية. لا يتطلب الإطلاق الأول توافق عملاء خارجيين غير موجودين؛ تبقى حماية الإصدارات المشروطة مفعّلة.

التراجع عن كود Sites لا يستعيد D1/R2. بعد المخطط الجديد لا يُعد الكود القديم القابل للكتابة تراجعًا آمنًا لكل عمليات الملفات. استخدم احتواء الكتابة بكود متوافق وإصلاح النشر للأمام، وافحص أي نشر جزئي قبل تكراره. يظل تعافي المزوّد الشامل قيدًا معلنًا، وليس مانعًا جديدًا للعملية 18 التي وافق عليها المالك.

المسودة الحالية ليست إصدار Stable عامًا. بصمة ZIP النهائية `4fa722ff400864bd86a731a8615191b9e6b1564f4a1a2b4b53167edf7ce3c60c` وبصمة الملف التنفيذي `33d7bbfe6a5deacfffd9f4a6ac31d4af41e39b2d6f935c9b656ab872c303dae7`. نجح تحديث صفحة الجوال وبقاء الجلسة والخروج ثم التحديث بعرض375 بكسل دون تجاوز أفقي، وظهر المقال والمقتطف اللذان أنشأهما Windows في موقع الكمبيوتر بالحساب الاصطناعي نفسه. High-DPI قيد تغطية غير مختبَر وليس عيبًا مثبتًا؛ يبقى تسليم التحديث المباشر بوابة قبول فعلية ولم تُفعّل بياناته الرسمية.
