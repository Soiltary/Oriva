# متابعة الاختبار الفعلي — 2026-10-25

[English](qa-followup.md) | [العربية](qa-followup.ar.md)

الاختبارات على جهاز Windows محلي ببيانات وهمية وD1/R2 معزولين. هذه متابعة للمصدر، وليست إعلان إصدار مستقر أو قبول الإنتاج.

## العيوب المصححة

1. كانت الواجهة تعيد استخدام جلسة استعادة سبق التراجع عنها، فتتعطل إعادة تحضير الملف نفسه. أثبت اختبار React الفشل قبل الإصلاح. يُحذف المعرّف بعد التراجع، وتبدأ جلسة جديدة للمعرّف المتراجع أو المفقود404. تبقى الجلسة عند401/500 لاستئنافها بلا تكرار، والجلسة المكتملة لا تنسخ المحتوى مرة أخرى. يعمل بديل في الذاكرة عند تعذر sessionStorage.
2. عُرّبت أخطاء سلامة النسخة وعدم اكتمالها والصيغة غير المدعومة وانتهاء الجلسة والفشل العام. لا يُحضّر ملف فشل التحقق من بصمته.
3. بعد الخروج بالعربية كانت نافذة Windows تصغر مع بقاء مواضع الحقول المادية خارجها. يُعاد الآن ضبط إحداثياتها المنطقية عند تخطيط شاشة الدخول وتغيير الحجم، مع الحفاظ على التطبيق وإعداد الإنتاج.

الملفات الأساسية: `app/backup-panel.tsx` و`desktop/windows/Oriva.c` و`desktop/windows/oriva-auth-layout.h`. اختبارات الانحدار في `tests/backup-panel.mjs` و`tests/run.mjs` و`tests/native-auth-layout.c`.

## التحقق

نجحت مجموعات JavaScript الـ21 في المصدر الخاص والنسخة العامة المنقحة، وTypeScript وبناء الويب. تشمل استعادة الملف بعد التراجع ومعرّفات404 والجلسة المكتملة وإعادة المحاولة401/500 والتخزين المحجوب والأخطاء العربية. نجحت من المتصفح العربي الفعلي الاستعادة والتراجع القابل للاستعادة ثم استعادة الملف نفسه ثانية مع بقاء مقال سابق. رُفض ملف تالف برسالة عربية قبل التحضير.

جُرّبت واجهة Windows الرئيسية بحسابات وهمية: الدخول والبحث والمفضلة والأرشفة والتبديل للعربية وتجميع المجموعات والخروج. أكدت قراءة البيانات بقاء الرابط والملاحظة والوسوم والمجموعة عند تعديل الأعلام. نجح الدخول والخروج بالعربية بعد الإصلاح لمكتبتَي100 و1,000 عنصر وبقيت حقول الدخول داخل النافذة. نجح اختبار Win32 مخفي في80 انتقال حجم مع تبديل LTR/RTL، دون ملف حساب أو سجل Windows أو شبكة. أمر تجميعه موثق في [التقرير الإنجليزي](qa-followup.md).

جُمّع ملف اختبار Windows x64 محصور في loopback واجتاز اختبار D1/R2 المحلي الفعلي للدخول وإنشاء/تعديل المقال والمكتبة ورفع/تنزيل ملف مطابق والخروج. أكد فحصه غياب اسم مضيف الإنتاج واستيرادات السجل وتشغيل البرامج. جُمّع إعداد الإنتاج منفصلًا ولم يُنفّذ. أظهر فحص الاعتماديات المحدث صفر تنبيهات معروفة؛ لا يشمل ذلك الثغرات غير المعروفة.

## قياسات الحجم والحدود

|عدد العناصر الوهمية|أول100 سجل|عدم التغيير|القائمة القديمة كاملة|
|---:|---:|---:|---:|

|1,000|7.575ms /49,490B|6.664ms /30B|21.643ms /441,588B|

هذه عينات مفردة لطلبات HTTP على المحاكي المحلي تشمل تحويل البيانات، وليست قياس زمن رسم Windows أو الإنتاج ولا إثبات تحسن جديد. طابقت القوائم أعدادها وملاحظة عربية/إنجليزية طويلة من11,930 وحدة نصية. عرض Windows الأعداد100 و1,000 و10,000. لكن عند10,000 فشلت قراءة شجرة الوصول وظهر توقف مؤقت عند محاولة التفاعل؛ لم يُحسم أثر التطبيق مقابل أداة الوصول. لذلك لم ينجح قبول التفاعل الكامل بهذا الحجم. أظهرت عينة عملية واحدة قرابة267MiB مجموعة عمل و258MiB ذاكرة خاصة؛ ليست هدفًا مقبولًا للأداء.

يفتح محرر المقال الأصلي، لكن أداة الإدخال المتاحة لا توجه الكتابة إلى نافذته التابعة؛ لم يُدّعَ حفظ مقال من واجهته. اختبارات المقال الآلية دليل منفصل. لم تُجرَ عملية تثبيت أو تعديل السجل أو قبول تحديث مثبت أو اختبار جهاز هاتف فعلي.

## الإنتاج والنشر

موصل Sites القائم ما زال يملك وصول المشروع، لكن عملياته المعروضة لا توفر تصدير D1/R2 كاملًا مقترنًا وتجربة استعادة معزولة مثبتة لكل الحسابات والمخطط والفهارس وسجل الترحيلات وبايتات الملفات وبياناتها الوصفية. لا يملك المالك حساب دخول منفصلًا للمتصفح؛ لا يوجد طلب دخول معلّق ولا حاجة لإنشاء حساب جديد لا يثبت ملكية هذا المشروع. لم نستنتج غياب نسخ داخلية لدى المزود.

تصدير المكتبة وتراجع المصدر لا يستعيدان جميع الحسابات والملفات ولا يتراجعان عن تغييرات البيانات. الاستراتيجية الآمنة حاليًا: إبقاء الإنتاج القائم، ونشر تصحيحات المصدر المنقح مستقلًا، وطلب التقاط واستعادة وسجل ترحيلات من المزود لهذا المشروع عبر قناة دعم خاصة معتمدة. [قالب الطلب](provider-recovery-request.md) جاهز ولم يُرسل تلقائيًا. إلى حين التحقق، لا توجد آلية استعادة مثبتة للحسابات والجلسات وملفات R2 غير الملتقطة بصورة مستقلة وكاملة. التجارب الوهمية المحلية لا تثبت تعافي الإنتاج.

لم تتغير ملفات SQL أو بيانات تاريخ الترحيل. يحتاج مقترح الفصل ونقل المجموعات المحدود إلى سجل المزود قبل التفعيل. ترفض التعديلات القديمة بلا revision برمز428 لمنع فقدان البيانات؛ توافق الكتابة المتزامنة1.5.3 لم يُحل. نجح اختبار ترتيب1.0.0 العام/2.0.0 للمحدّث، وهو منفصل عن توافق الكتابة. ما زالت سعة واحتفاظ الاستعادة واختبارات التحمل والمحرر/الحجم الكبير/التحديث المثبت والهاتف بوابات مفتوحة.

لم يُنفذ ترحيل أو نشر إنتاج أو حذف بيانات مستخدم أو تغيير تغذية تحديث حية أو وسمv1.0.0 أو إصدار Stable أو حزمة Windows عامة. راجع [حالة الإصدار](windows-release-status.md) و[أمان النشر](deployment-safety.ar.md).
